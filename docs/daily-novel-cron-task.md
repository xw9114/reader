## 🎯 详细创作与技术规范

### 一、短篇小说创作规范（每日 3 篇）
1. **题材多维度发散**：
   - 每次分别在三大热门赛道布局（如：1. 苟道修仙/截胡女帝；2. 都市神豪/多子多福；3. 反派穿书/宗门女尊修罗场）。
2. **字数与分章**：
   - 每篇字数 **10,000 ~ 30,000 汉字**，精简紧凑，分为 6~10 章。
3. **Reader 格式与简介钩子**：
   - 首行：`# 作品名称`
   - 第二行紧随：`## 开篇钩子`（250~400字核心高潮爽点，供 Reader 浏览器插件完美提取简介）
   - 各章节：`## 第N章 章节名称`
   - 正文自然分段空行，全篇中文标点。
4. **封面自动生成**：
   - 必须调用图像生成系统，生成 2:3 纵向比例、角色贴合、纯净无任何水印和字母文字的高清封面。
   - 文件名：`covers/<小说文件名stem>.jpg`。
5. **平台角色与标签声明卡**：
   - 每次生成完毕后，自动输出【七猫/番茄平台专用·角色与标签声明卡】：
     - 正式男主角名、女主角名；
     - 【角色】标签（1~3个）；
     - 【风格】标签（1~3个）；
     - 【情节】标签（1~3个）；
     - 【背景】标签（1~3个）。

---

### 二、长篇小说连载规范（每日 3 章）
1. **章节严格自增连续**：
   - 扫描当前目录下最大章节号（如 `0002`），连续生成接续的 3 章（如 `0003`、`0004`、`0005`），绝不跳号、断号。
2. **大纲与人设推进**：
   - 按照 `book.json` 规划的分卷卷名与范围推进。
   - 保持每章 2500~3500 字，节奏明快、后宫修罗场争宠、反差萌与爽点连贯。
3. **封面保障机制**：
   - 自动检测该作品在 `covers/<readerId>.*` 是否存在封面，缺漏时自动补齐。

---

### 三、自动构建、测试与 Git 远端推送
两项任务生成完毕后均会自动执行完整流水线：
1. **构建发布包**：`python tools/build_publish.py`，更新 `dist/` 与作品索引。
2. **全套自动化测试**：
   - `python -m unittest discover -s tests -q`
   - `node tests/test_extension_browser.js`
3. **Git 仓库同步**：
   - 自动暂存新增小说与封面：`git add -- daily/ serial/ covers/`
   - 提交信息规范：`git commit -m "content: ..."`
   - 变基拉取并推送：`git pull --rebase origin main` -> `git push origin main`。
