Reader 小说平台导入助手安装方法

1. 将下载的 ZIP 完整解压到一个固定文件夹。
2. Chrome 打开 chrome://extensions/，Edge 打开 edge://extensions/。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择这个文件夹。
5. 登录番茄网页作者后台或七猫作者中心。
6. 打开作品信息、章节或短故事编辑页，使用右下角的“Reader 导入助手”选择作品。
7. 点击对应的填入按钮，核对内容并补充平台必填选项后再保存或发布。

扩展从以下地址读取稿件：
https://xw9114.github.io/reader/data.json
