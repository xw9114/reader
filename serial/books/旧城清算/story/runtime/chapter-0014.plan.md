## 场景与篇幅预算
- 场景 1：许知微完成三份拆分申请递交，核对周岚收到通知的日期与配合期限，明确六月十九日下班前只剩两个工作日｜约 700 字
- 场景 2：许知微转去市公共资源交易旧公告库和市图书馆政务资料室，靠采购编号翻出二〇二一年中标公告，确认HZCG2021-UG-0417的中标单位为启衡律所｜约 1100 字
- 场景 3：母女回到旧城社区联络点，以“仅转交、是否回应由本人决定”的方式向孙、罗两户递出核验说明；周岚有限展示一张原始安置凭据的非敏感编号面，母女重新划定证据使用边界｜约 700 字

## 当前任务
许知微要以公开中标公告把HZCG2021-UG-0417与启衡律所钉在一起，同时在六月十九日截止前完成不侵犯孙、罗两户权利的协作入口；本章许知微、周岚围绕“原始凭据能否给女儿看、别人家的材料能否被卷入”各从自己的利益和恐惧过一次。

## 读者此刻在等什么
1) 读者现在期待：专项法律服务采购究竟由谁承接，L-21-04是否会把许知微的旧婚姻与父亲的补件牵进同一条线。  
2) 本章对这个期待做什么——部分兑现：公开采购结果确认启衡律所中标，但不把中标直接等同于L-21-04出具方，更不替江惟林定罪。

## 该兑现的 / 暂不掀的
- 该兑现：HZCG2021-UG-0417的中标单位身份 → 许知微取得可保存、可核对发布日期和公告编号的公开中标公告，确认启衡律所确曾承接兴港里专项法律服务。
- 该兑现：周岚对原始安置凭据的开放程度 → 她允许许知微核对一张凭据的编号、日期和纸张状态，但原件仍不交出、不允许脱离母女共同控制使用。
- 暂不掀：L-21-04正文及出具人员 → 留到第15—16章，必须先取得合同归档、委托范围或付款附件中的可核验关联。
- 暂不掀：江惟林本人是否经手该项目 → 留到第16章后，许知微在没有合同人员名单、工时记录或意见书落款前不联系他。
- 暂不掀：父亲“补件”的具体内容 → 留到第17章以后，先让专项清算工作组承接链和安置凭据编号发生交叉。

## 日常/过渡承担什么任务
- [场景1递交申请后的步行与午间整理] → 用许知微逐项核对日期、回执编号和通知落款，修复倒计时信息：通知于六月十二日送达，六月十三日至十七日已消耗三个工作日，六月十八日、十九日为仅余两个工作日，截止为六月十九日十七时三十分。
- [场景2资料室检索间隙] → 展示许知微的审计习惯：先保存公告页面、核验发布主体与编号，再比对项目名称和服务期限，不把搜索结果直接当成案件结论。
- [场景3社区联络点外的简餐或归家整理] → 给连续紧绷的母女关系一次有分寸的松动：周岚仍挑剔许知微的措辞，许知微仍不肯示弱，但两人共同把材料分袋、贴明权限，形成实际协作。

## 关键抉择过三连问
- 主角本章最关键的一次选择：
  - 为什么这么做？许知微查到启衡律所中标后，不立刻联系江惟林，也不以旧关系换取内部信息，而是先保存公告、继续走合同归档和付款附件两条线。
  - 符合当前利益吗？符合。她避免惊动可能掌握材料流向的人，也避免一份公开公告被对方轻易解释为她的私人报复。
  - 符合她的人设吗？符合。她较真、耐烦，宁可多走几步笨路，也不愿欠人情或让证据因关系瑕疵失效。
- 对手/配角本章最关键的一次选择：
  - 为什么这么做？周岚决定让许知微核对原始安置凭据的编号面，同时坚持原件不离开铁盒，孙、罗两户的材料只能经社区代转授权说明。
  - 符合当前利益吗？符合。她需要女儿继续查清第017行，却不能让自己的安置权益、其他住户的权利或许敬和留下的材料失去控制。
  - 符合她的人设吗？符合。周岚不是忽然完全信任女儿，而是在见到许知微守住边界后，给出一次有限而可撤回的让步。

## 章尾必须发生的改变
- 信息改变：HZCG2021-UG-0417从抽象采购编号变为“启衡律所中标的兴港里专项法律服务”这一条可公开核验的事实。
- 关系改变：周岚第一次主动拿出一张原始安置凭据供许知微核对，母女从“母亲保管、女儿申请”变为共同设定材料权限。
- 权力改变：许知微给孙、罗两户留下独立授权入口，异常住户线不再只能由她单方面推测，但是否加入仍完全由当事人决定。

## 本章 hook 账
**这是本章对活跃伏笔的账本，写手必须按这份账动作。格式如下（每个分类下用 - 列表）：**

open:
- 无新增钩子；本章不再扩张活跃线索数量，章尾以既有H007和L-21-04的关联缺口承接。

advance:
- H006 “母女关系” → 周岚从铁盒中取出一张原始安置凭据，仅允许许知微核对编号、日期与凭据状态；原件继续由周岚保管，任何提交或复制须共同确认。
- H007 “职业冲突” → 公开中标公告确认启衡律所承接HZCG2021-UG-0417，但许知微明确不联系江惟林，不将律所中标等同于他本人经手或L-21-04来源。
- H012 “采购文号缺口” → 许知微取得并保存带发布主体、公告日期、项目名称的中标公告，确认采购编号、兴港里项目与启衡律所之间存在公开采购关系。
- H004 “形成可互证的异常住户链。” → 许知微与周岚制作同式核验说明，经社区仅作转交给孙、罗两户；说明按“公开坐标—各户自有材料—授权范围”分栏，避免把他户资料混成既成证据链。
- H010 “确认罗家留存材料、权利状态及缺失档案去向。” → 给罗家转交的说明只询问其是否愿意自行联系、是否愿意授权核对其留存材料，不索取、不查看罗家原件；罗家是否回应成为下一步合法入口。
- mystery-017-017-查明法律复核-意见-的正文 → 启衡律所中标使L-21-04获得明确的待核验服务主体坐标，但仍缺合同范围、意见书正文和落款，不能确认对应关系。

resolve:
- 无。本章取得的是采购关系的公开坐标，不足以结清法律复核意见、伪造签收或父亲补件的任何核心问题。

defer:
- H002 → 本章不另行追查，理由：许知微必须先把六月十九日的核验配合与专项法律服务合同链固定，避免同时摊开父亲遗留材料而超出周岚刚刚允许的边界；第15章随承接单位核验继续推进。
- H008 “确认页指印” → 本章不动，理由：现有公开中标公告只能确定外部法律服务坐标，确认页仍须从安置结算组调阅记录或原始确认材料切入，留到第16章。
- mystery-2021-查明-结算复核组-将周岚列入异 → 本章不动，理由：周岚展示的凭据只能提供编号交叉点，不能替代结算复核组的名单形成记录，等待专项清算工作组承接线的书面核验。

## 不要做
- 不把启衡律所中标直接写成江惟林经手、L-21-04出具或伪造签收的证据。
- 不让许知微通过私下电话、前婚姻关系或饭局向江惟林套取材料。
- 不让孙、罗两户突然交出完整材料、同意并案或替许知微作证；社区只能代转，不得透露他们的个人档案状态。
- 不再以“窗口递件—等回执”作为全章主要行动形态；检索中标公告、核验原始凭据、设计授权边界必须成为可见动作。
