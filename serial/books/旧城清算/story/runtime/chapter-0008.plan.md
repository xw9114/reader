# 第 8 章 memo

## 本章目标
完成第017行档案的线下身份关联核验，锁定其异常移交流向

## 关联线索
- H001
- H006
- H008
- H010

## 场景与篇幅预算
- 场景 1：许知微核对线下核验材料要求，明确旧住址证明只能证明身份关联、不能替代补偿权利主张｜约 650 字
- 场景 2：许知微向周岚借取旧房承租与迁移材料，母女围绕“查到什么程度”发生克制冲突｜约 900 字
- 场景 3：许知微在区城市更新服务中心完成原件核验，得知第017行档案曾在二〇二一年被“退回补件”且去向栏为空｜约 1000 字

## 当前任务
许知微带着能证明自己与旧城项目地址关联的原件完成线下核验，并拿到第017行档案异常移交状态的正式查询线索。

## 读者此刻在等什么
1) 许知微名下286,400元补偿款的签收、经办和编号变更，究竟能否从第017行档案中查到。  
2) 本章部分兑现：她获得进入档案链条的正式资格，却先发现第017行在库房调整中被退回补件，签收页仍未出现。

## 该兑现的 / 暂不掀的
- 该兑现：H001“许知微名下补偿款签收与第017行改号” → 完成身份关联核验，确认第017行并非普通已归档状态，而有二〇二一年“退回补件”的目录痕迹。
- 暂不掀：第017行具体签收人、签收时间和286,400元的付款去向 → 留到第10章前后取得业务档案室或区档案馆的进一步书面答复后再核。
- 暂不掀：许敬和为何修改编号、为何沉默 → 留到第15章后有相邻批次底档或确认页留痕可供比对时再推进。

## 日常/过渡承担什么任务
- [场景1开头的材料整理] → 交代许知微不用“女儿”身份模糊顶替项目关联人，而是逐项区分身份证明、旧址居住证明与补偿权利证明，显示她的职业习惯。
- [去周岚住处前的路程与天气] → 用旧城潮湿的楼道、迁移通知纸张的霉味和塑料文件袋的摩擦声，连接父亲留下的台账与眼下必须拿原件核验的现实压力。
- [窗口等候与表格填写] → 展现程序并不因主角着急而让路，同时让许知微观察档案分类、受理权限和工作人员措辞，为后续追查业务档案室与档案馆做准备。
- [本章核心冲突的多视角] → 场景2以周岚交不交原件为圆心：许知微从“不能让个人查询卡在身份说明上”的角度衡量；周岚从“旧材料一旦离手，旧城住户可能再次被牵连”的角度抗拒。两人都要各自有一段独立内心反应，不把周岚写成单纯阻挠者。

## 关键抉择过三连问
- 主角本章最关键的一次选择：
  - 为什么这么做？许知微不接受只在线上补一段自述，而是坚持带原件去窗口核验，避免自己的查询以后被以身份关联不足为由驳回。
  - 符合当前利益吗？符合。她需要的是可留痕、可复核的查询入口，而不是口头承诺或临时通融。
  - 符合他的人设吗？符合。她较真且耐烦，宁可多跑程序，也不愿把母亲的旧材料混同为补偿资格证明。
- 对手/配角本章最关键的一次选择：
  - 为什么这么做？周岚最终只借出旧房承租证和迁移通知原件，并要求许知微当日归还、不许擅自复制其中涉及他人的页面。
  - 符合当前利益吗？符合。她既不愿女儿因材料不足被挡在门外，也要守住旧城材料扩散后可能伤及住户的风险。
  - 符合他的人设吗？符合。周岚长期回避旧事，但不是冷漠；她愿意让步，却必须把边界握在自己手里。

## 章尾必须发生的改变
- 信息改变：第017行历史档案已完成本人身份关联核验，但目录显示其二〇二一年曾被“退回补件”，现去向栏为空。
- 关系改变：周岚首次把旧房相关原件交到许知微手里，但附带严格用途与归还边界，母女关系从回避变成有限协作。
- 权力改变：许知微取得加盖受理章的线下核验回执，可据此向业务档案室和区档案馆继续申请对应的补件、移交与目录记录。

## 本章 hook 账
**这是本章对活跃伏笔的账本，写手必须按这份账动作。格式如下（每个分类下用 - 列表）：**

open:
- [new] 第017行目录标注“退回补件”，去向栏为空 || 理由：线下核验只能显示目录状态，补件内容和接收人须待调取业务档案室交接记录后才能确认。

advance:
- H001 “许知微名下补偿款签收与第017行改号” → 许知微完成本人原件核验，取得正式回执，并确认第017行在二〇二一年库房调整后存在“退回补件”记录（progressing → pressured）。
- H006 “母女关系” → 周岚在明确不得扩大用途的条件下，交出旧房承租证和迁移通知供当日核验；她仍拒绝谈许敬和当年的具体处境（deferred → progressing）。
- H008 “确认页指印” → 窗口人员仅能按档案分类说明，罗秀兰所述的入住确认类单页若存在，应不在许知微个人补偿档内，而可能落在业务档案室的入住、调房或驻场登记材料中（progressing → pressured）。
- H010 “罗家原始材料” → 许知微明确罗家缺失单页不能靠个人档案查询补齐，后续需以登记册、调房记录和业务归档目录交叉寻找（progressing → pressured）。

resolve:
- 无：本章不具备取得签收原件或确认页原件的条件，不将目录异常误写成造假结论。

defer:
- H003 “家庭秘密” → 本章只让周岚表现出对旧材料外流的恐惧，不追问许敬和沉默原因；等到第15章左右有可核对的底档事实再触及。
- H005 “资金链” → 本章不申请付款附件或推断补偿款流向；等取得采购文号、合同主体或结算目录后再进入。
- H007 “职业冲突” → 本章不联系江惟林及启衡律所，避免在尚无可核验合同、融资或处置文件时提前消耗这条线。

## 不要做
- 不让窗口工作人员直接调出完整签收页、付款凭证或经办人姓名；本章只能拿到核验受理与目录层面的异常状态。
- 不把周岚交出的承租证、迁移通知写成补偿资格、继承资格或对伪造签收的直接证据。
- 不让许知微以亲属关系要求工作人员越权查档，也不让她偷拍、偷录或擅自复制受限档案页面。
- 不让周岚突然坦白父亲的全部秘密；她的让步必须有限、警惕，并保留自己的顾虑。
