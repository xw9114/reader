# 第 1 章 memo

## 本章目标
抛出离婚日的冒名补偿签收与复核倒计时

## 场景与篇幅预算
- 场景 1：民政局办完离婚，许知微与江惟林切断婚姻关系；从他的工作来电和回避态度中带出启衡律所与旧改项目的潜在关联｜约 700 字
- 场景 2：许知微去兴港里旧宅见母亲周岚，拿到父亲许敬和留下的一页补偿台账，发现自己“已签收”一笔从未领取的补偿款；母女因是否追查爆发第一次正面冲突｜约 1050 字
- 场景 3：许知微回到租住处，以审计习惯核对台账编号、项目公开资料和资格复核要求，确认名单即将固化、窗口有限，并发现台账边角的经办编号有父亲修改痕迹｜约 750 字

## 当前任务
许知微必须确认那笔写着她名字的补偿款真实存在，并在名单固化前决定启动资格复核。

## 读者此刻在等什么
1) 读者现在期待：许知微为何在离婚当天收到父亲遗留台账，以及“已签收”的钱究竟被谁领走。  
2) 本章对这个期待做什么：部分兑现台账内容和程序风险，不确认伪造者身份；用父亲改过的编号把追查方向推向旧改经办链条。

## 该兑现的 / 暂不掀的
- 该兑现：许知微名下存在一笔“已签收”补偿款 → 让她亲眼核对姓名、金额、签收状态与自己从未收款的事实。
- 该兑现：父亲遗物确实指向兴港里旧改项目 → 台账页有项目名称、住户序号和父亲留下的手改编号。
- 暂不掀：签收是否系伪造、由谁伪造 → 留到第 3—5 章取得签收底单或银行支付路径后再判断。
- 暂不掀：许敬和当年为何改号又沉默 → 留到第 8 章前后，通过经办资料和旧邻证言逐步揭开。
- 暂不掀：周岚手中的原始安置材料 → 她明确承认还有东西，但拒绝交出，留到第 6 章前后。

## 日常/过渡承担什么任务
不适用 - 本章无日常过渡；民政局、旧宅和租住处三段均直接推动离婚断裂、台账发现与复核行动。

## 关键抉择过三连问
- 主角本章最关键的一次选择：
  - 为什么这么做？许知微明知母亲抗拒、自己刚结束婚姻，仍决定不把台账塞回抽屉，而是核实资格复核入口。
  - 符合当前利益吗？符合。名单一旦随资产处置材料固化，她之后再主张自身权利和住户异常都将更被动。
  - 符合他的人设吗？符合。她不急着指控任何人，只按审计逻辑拆分姓名、编号、签收状态和程序期限，克制但不肯放过疑点。
- 对手/配角本章最关键的一次选择：
  - 为什么这么做？周岚只交出台账页、扣住其余材料，要求女儿别碰旧城旧账。
  - 符合当前利益吗？符合。她仍住在兴港里，担心追查会影响自己和其他住户尚未落实的安置、过渡与居住处境。
  - 符合他的人设吗？符合。她不是无端阻拦，而是在知道风险却无法说明全部原因时，选择用强硬态度保护女儿和自己。

## 章尾必须发生的改变
- 信息改变：许知微确认台账并非泛泛旧账，而是记有她本人“已签收”状态的具体补偿记录。
- 权力改变：兴港里已结算名单存在明确固化期限，许知微必须在有限窗口内走资格复核程序。
- 关系改变：母女第一次因父亲旧账撕开隔阂；周岚的拒绝让许知微确定她知道得比说出来的多。

## 本章 hook 账
**这是本章对活跃伏笔的账本，写手必须按这份账动作。格式如下（每个分类下用 - 列表）：**

open:
- 无新增钩子；本章只将开篇既有线索落到可核查的纸面与期限上，避免分散调查方向。

advance:
- H001 “身份异常” → 许知微核对台账，确认自己名下补偿款标注“已签收”，而她从未领取（deferred → pressured）
- H002 “程序时限” → 许知微查到兴港里已结算名单将随资产处置材料固化，资格复核窗口所剩不多（deferred → pressured）
- H003 “家庭秘密” → 台账经办编号旁有许敬和亲笔涂改、重写的痕迹，说明他曾发现或介入异常（deferred → pressured）
- H006 “母女关系” → 周岚承认父亲留下的不止这一页材料，却拒绝交出并阻止许知微追查（deferred → pressured）
- H007 “职业冲突” → 江惟林的启衡律所身份在离婚现场自然露出；许知微随后查到启衡与兴港里资产处置存在业务往来，但尚不知江惟林参与程度（deferred → pressured）

resolve:
- 无

defer:
- H004 “群体证据” → 本章仅从台账住户序号看出记录并非孤例，不锁定具体旧邻；等第 3 章走访兴港里后再形成第一组可互证异常。

## 不要做
- 不让江惟林在本章解释律所业务、替许知微查资料，或以私人关系替她打开程序入口。
- 不让周岚一次性交出完整档案、火灾真相或父亲遗言；她只能给出有意保留的一页台账。
- 不在本章确认签名伪造、锁定责任人或把补偿款去向查清。
- 不用大段回忆交代婚姻史、旧改历史或父亲生平；所有信息必须通过离婚手续、台账核对和程序查询落地。

## Intent
Intent Goal: 抛出离婚日的冒名补偿签收与复核倒计时
Outline Node: 全书分为四卷。第一卷的主题是“名字被谁写走”，情绪从离婚后的疲惫和私人羞耻，逐渐收紧为窗口前无处可退的愤怒；它的爽感来自许知微用专业习惯从一堆“手续齐全”里抠出第一处裂缝，但裂缝后面露出的恰好是父亲。第二卷的主题是“钱去了哪里”，情绪更快、更硬，住户联盟、律所、银行和项目公司开始真正互相施压，许知微赢得程序位置，也被迫看清前夫江惟林所在律所并非旁观者。第三卷的主题是“火没有烧完”，旧火灾证据让故事进入最冷的一段，家庭秘密把许知微从受害者的位置推向复杂的继承者位置。第四卷的主题是“补救由谁付账”，高潮不只在公开责任，更在住户彼此撕扯之后仍要形成现实方案；结尾的暖意来自重新建立的秩序，而非所有伤口自动愈合。

### Must Keep
- 罗业清（主要）：罗业清是海城更新公司兴港里项目负责人，正为项目贷款展期和安置房处置奔走。 他必须让“已结算住户”名单在外部评估前保持稳定，否则项目资产价值会被重估，自己多年积累的信誉和晋升机会都会受损。 他对许知微的存在尚无明确警觉，只把她归入旧城项目里常见的遗属咨询。
- 许知微（主要）：许知微住在海州市一间月租三千二百元的一居室里，刚办完离婚手续，正准备重新找内审或合规岗位。 她手头存款够撑几个月，却不愿回兴港里和母亲挤在临时安置房。最近最烦心的，是前单位的离职竞业条款尚未完全解除，而她又不想向任何旧同事开口求工作。 她仍保留着审计工作时的习惯：手机相册按日期建文件夹，票据拍完会立刻写备注，睡不着时就把旧邮件一封封归档。

### Must Avoid
- 不以巧合掉落完整证据链。
- 不让反派降智、主动坦白或无代价配合。
- 不用一个电话、一次关系饭局解决程序问题。
- 不把女性角色写成奖励、陪衬或情绪工具。
- 不以媒体曝光替代证据、责任认定与补救执行。
