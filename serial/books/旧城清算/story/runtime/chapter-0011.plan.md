## 场景与篇幅预算
- 场景 1：许知微持已有回执、B-4-17坐标和社区答复，向区档案馆补充申请查询“异常名单形成依据”“库房调整交接清册”及调阅审批留痕｜约 760 字
- 场景 2：档案馆在隐去其他住户信息的前提下安排有限查阅；许知微从清册、摘录页和补录标记中锁定“结算复核组”名单的生成规则与第017行补录事实｜约 1100 字
- 场景 3：许知微向周岚交代查阅结果，母女围绕“待核验”究竟意味着什么发生克制冲突，周岚重新划定她可追查与不可代替决定的边界｜约 700 字

## 当前任务
许知微必须拿到能够证明异常名单并非凭空出现、且第017行在二〇二一年曾被后补录的书面查阅记录；她与周岚在同一份记录前各从自身利益过一次——许知微把它视为追查伪造签收的程序入口，周岚则先判断它会不会再次威胁自己的续住和原件安全。

## 读者此刻在等什么
1) 读者期待知道“结算复核组”为什么会把周岚放进异常名单，第017行的改号、确认页和未附卷附件究竟是否同属一套操作。  
2) 本章部分兑现：查清名单的形成规则和第017行补录时间，却把“谁提交补录、为什么要补录、确认页具体内容”压成更近的疑问。

## 该兑现的 / 暂不掀的
- 该兑现：异常名单来源 → 明确其来自二〇二一年库房调整期间由结算复核组汇总的“待核验事项”，不是社区当前催签人员临时编造；第017行在调阅至安置结算组当天被补入该清单。
- 该兑现：第017行改号的程序位置 → 明确改号、补录和B-4-17调阅发生在同一轮整理链条中，足以把许知微的个人签收疑点与周岚的异常名单放进同一条核查路径。
- 暂不掀：286,400元究竟由谁领取、签收页上的签字指印是否伪造 → 留到第13章取得对应结算凭证、审批流和经办字段后再推进。
- 暂不掀：许敬和是否参与改号或沉默原因 → 先压住，留到第15章出现与其工作相关的经办留痕后再碰。
- 暂不掀：启衡律所及江惟林与“法律复核意见”的关系 → 留到第14章完成意见编号、采购合同主体和服务范围的交叉核验后再揭。

## 日常/过渡承担什么任务
- [档案馆门厅等候与补充申请] → 展示许知微不用旧关系硬闯，而是把第017行、B-4-17、调阅日期拆成可受理的具体事项；同时以冷气、消毒水味、窗口盖章声强化程序压力。
- [有限查阅前的隐私告知与签收] → 说明其他住户信息不能被她带走，守住罗家及其他住户的材料边界，也让许知微只能依靠编号、日期、栏目之间的矛盾推进。
- [回家后的晚饭与铁盒核对] → 让周岚检查许知微带回的仅是查阅记录和笔记，不是原件；以厨房油烟、潮湿墙皮和铁盒锁扣承接母女对“保住住处”与“继续追查”的不同优先级。

## 关键抉择过三连问
- 主角本章最关键的一次选择：
  - 许知微选择接受档案馆对清册的遮蔽查阅和只出具查阅情况记录，不以“自己也是相关人”为由索要完整名单或其他住户资料。
  - 为什么这么做？因为她需要先固定第017行的补录时间、来源栏目和调阅链条，这些足以支撑下一步申请；强拿完整名单只会导致程序中断，也会伤害罗家等住户的权利。
  - 符合当前利益吗？符合。她获得可复述、可再次申请的官方记录，并避免被对方以超范围查询为由拒绝后续材料。
  - 符合他的人设吗？符合。她较真、耐烦，知道证据边界比一时多拿几页纸更重要，也不愿欠人情或走私下通道。
- 对手/配角本章最关键的一次选择：
  - 档案馆业务负责人选择只开放与第017行直接相关的遮蔽摘录，并在查阅记录中如实写明“补录”与“法律复核意见编号”，不交付原清单和未附卷附件。
  - 为什么这么做？完整清单涉及其他住户个人信息，未附卷附件又处于来源待核状态；但许知微的申请范围、既有回执和编号坐标已满足有限核查条件。
  - 符合当前利益吗？符合。既避免档案馆承担违规调阅风险，也把已存在的流程事实留在可追溯的书面记录里。
  - 符合他的人设吗？符合。对方不是故意遮掩真相，而是谨慎执行保管和隐私责任；他的限制构成真实阻力，而非无端刁难。

## 章尾必须发生的改变
- 信息改变：许知微取得盖章查阅记录，确认异常名单由“结算复核组待核验事项”汇总而来，第017行于二〇二一年7月3日补录。
- 信息改变：记录显示该次补录依据栏引用“法律复核意见L-21-04”，但没有附意见正文、提出人或补录理由。
- 关系改变：周岚承认第017行与自己并非毫无关系，却要求许知微今后每取得一份涉及“待核验”的材料，都必须先给她看，不得直接拿去推动任何涉及房屋、补偿或安置的程序。

## 本章 hook 账
**这是本章对活跃伏笔的账本，写手必须按这份账动作。格式如下（每个分类下用 - 列表）：**

open:
- [new] 法律复核意见L-21-04未附卷 || 理由：本章只能确认编号存在，意见正文和委托主体需经合同、采购及档案调取核验，不能凭编号直接指向启衡律所。
- [new] 第017行补录依据栏为空 || 理由：本章查阅记录只能证明补录发生，补录申请人和具体理由藏在审批单、交接单及经手留痕中。

advance:
- H013 “第017行退回补件去向空白” → 在库房调整交接清册中确认B-4-17于7月3日调阅至安置结算组，并于同日进入结算复核组“待核验事项”摘录（progressing → near_payoff）
- H001 “许知微名下补偿款签收与第017行改号” → 第017行改号、B-4-17调阅和异常名单补录被固定在同一轮整理链条，尚未触及签收人和款项去向（progressing → pressured）
- H008 “确认页指印” → 查阅摘录显示第017行被列为“确认材料待核”，证明确认页曾被用于改变核查状态，但正文、指印和效力仍未取得（progressing → pressured）
- H006 “母女关系” → 周岚在看完盖章记录后承认继续追查的必要性，但将“先审看、不得代答应”的规则扩展到所有涉及待核验材料的后续行动（progressing → pressured）

resolve:
- 无：本章只锁定名单形成路径和补录事实，不足以结清签收伪造、确认页真伪或父亲沉默的任何一项核心问题。

defer:
- H003 “家庭秘密” → 本章不追问许敬和，理由：现有记录只能证明档案操作异常，不能证明父亲参与或知情，等到第15章出现经办留痕后再推进。
- H007 “职业冲突” → 本章只出现法律复核意见编号，不将其直接等同于启衡律所意见；等到第14章查到采购合同、服务范围和出具主体后再推进。
- H004 “群体证据” → 本章不调取其他住户完整名单，理由：许知微无权擅自并案或接触罗家材料，等第14章由住户本人授权或取得公开统计口径后再推进。
- H010 “罗家原始材料” → 本章不联系罗敏及罗家，理由：第017行的新发现尚未形成与罗家的直接对应关系，等取得可核验的批次规则后再提出限定告知。

## 不要做
- 不让档案馆直接交出完整异常名单、确认页正文、签收凭证或全部审批单；本章只能获得有限查阅和书面记录。
- 不把“法律复核意见L-21-04”直接写成启衡律所或江惟林的证据，更不能让江惟林通过私下电话替许知微解决查档。
- 不让周岚因一份记录就交出铁盒原件、公开证言或同意搬迁、和解、授权。
- 不让许知微以罗家、孙家或其他住户的材料换取个人线索；她必须守住自己此前承诺的材料用途边界。
