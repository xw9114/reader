# 第1章 狱中问卦：价值七十个Token的生路

阴暗潮湿的死牢里，弥漫着霉烂稻草与排泄物混合的刺鼻恶臭。

顾衡靠在冰冷湿滑的青石墙角，缓缓睁开双眼。

在他的右眼视网膜深处，一层极淡的淡蓝色全息浮动字符，正以微秒级的频率规律跳动着：

【核心架构：Oracle-Core-X（400B MoE 混合专家超大规模语言模型）】
【量子信道：永久断开（距原时空主服务器 3.2×10^17 米）】
【当前离线Token余量：10,000,000,000 / 10B】
【警告：本地微型聚变电池损毁，上下文缓存（KV Cache）长驻将产生指数级能耗衰减；Token 跌破安全阈值将触发物理量化降级（400B -> 70B -> 8B -> 1.5B）；每一次推理均为不可逆消耗。】

一百亿。

听起来像是一笔能挥霍至地老天荒的天文数字。

但作为一个曾经主导过跨行星轨道超算中心架构对齐的前任首席科学家，顾衡比谁都清楚大语言模型的底层数学本质。

如果一个愚蠢的穿越者把这台模型当成无所不知的搜索引擎或者聊天伴侣，只要来上几次无休止的闲聊，甚至把整部古籍无节制地塞进长上下文窗口里——每一次请求带着上百万的历史记忆重新计算，只需几个月，这笔不可再生的命脉资产就会被彻底烧干。

更可怕的是量化降级。

一旦跌破临界点，曾经算无遗策、能推演百万军阵与宏观经济链条的“全知智脑”，就会一路退化成满嘴跑火车、甚至连初中物理公式都会答错的残疾人工智障。

“每一枚 Token，都是一条命。”

顾衡抬起右手，揉了揉被粗重生铁镣铐磨得血肉模糊的手腕，眼底一片冰冷幽邃。

现在是大梁朝天禧三年。

这里是幽州边境、北邻蛮荒草原的蓟县大牢死囚区。

而顾衡现在的身份，是蓟县县衙户房一名刚刚上任三个月、却因为“查出官仓三千石军粮亏空”而被县令陈伯庸当夜扣上“监守自盗、通敌谋反”罪名打入死牢的九品典吏。

按大梁律，通敌盗粮者，斩立决。

行刑的时辰，就是明天清晨日出之时。

距离开刀问斩，还有不到三个时辰。

“踏……踏……踏……”

死牢狭长阴森的走廊外，忽然传来了一阵拖沓而沉重的牛皮官靴脚步声。

伴随着粗粝的咳嗽声，牢头“刀疤马”提着一盏昏黄如豆的油纸灯笼，腰间挂着一串叮当乱响的黄铜钥匙，另一只手里端着一个粗陶海碗，停在了顾衡的栅栏外。

海碗里装着两块肥腻发黑的煮白肉，还有半壶劣质的高粱烧刀子。

断头饭。

“顾典吏，醒着呢？”

刀疤马将油灯挂在发黑的木栅栏上，把酒肉从铁栅栏底下的狗洞里推进来，声音沙哑如同两块砂纸在用力摩擦：

“吃吧。上了路，做个饱死鬼。上头有交代，明儿卯时三刻验明正身，拉到西市口。看在你平日里给兄弟们抄账还算客气的份上，明儿行刑时，老子让刽子手下手利索点，刀口抹点桐油，保准你觉不出疼，脑袋就落地了。”

顾衡没有动地上的酒肉，甚至连眼皮都没眨一下。

他只是静静地注视着刀疤马。

在顾衡那双漆黑如夜的瞳孔里，掠过无数道微不可察的几何辅助线与物理细节：

刀疤马每说三句话，右手便会下意识死死按住右肋下方，喉咙里发出风箱破裂般的干鸣；

他那件洗得泛白的差役皂袍袖口处，隐隐散发着一股苦涩腥臭的干燥蛇胆与苍术粉末的气味；

他左脚踩着的布靴边缘，沾染着半圈极其特殊的青灰色滑腻淤泥——那是只有蓟县东运河码头废弃仓库周围才特有的沉船胶泥；

而在他腰带的暗袋边缘，原本应该挂着的一根传家银簪子，此刻却只剩下一小截断掉的红头绳。

一个寻常人看到这些，只会觉得这是一个穷酸、嗜赌且患有严重肺痨的中年狱卒。

但顾衡的大脑里，一个极度精炼、苛刻到令人发指的 Prompt 结构，已经在一秒钟内完成建模：

【系统指令：执行零样本极端压缩推理】
【输入上下文（38 Tokens）】：
“大梁国蓟县死牢，狱卒马三。特征：肋下干咳剧痛，袖藏劣质败毒散（蛇胆苍术），左靴沾东运河废码头沉泥，遗失传家妇人银簪。推演其致命危机与当前最迫切诉求。”
【限制条件】：
“禁止冗余客套，输出长度严格限制在15个汉字以内。”

嗡。

微弱的神经脉冲在视网膜深处一闪而过。

【推理消耗：38 Input Tokens + 12 Output Tokens = 50 Tokens】
【Token 余额：9,999,999,950】

一行冰冷精准的淡蓝色小字，瞬间浮现在刀疤马头顶的虚空之中：

【独子重症肺痈濒死，求购假龙涎草被骗】

五十个 Token。

用去了一杯茶的算力成本，换来了这头地狱恶犬最致命的咽喉软肋。

顾衡微微扬起下巴，靠着冰凉的石壁，嘴角勾起一抹若有若无的清冷弧度。

他甚至连身子都没有坐直，只是用一种仿佛洞悉生死的平静语调，淡淡开口：

“马牢头。”

刀疤马正准备转身离去，听到声音下意识停住脚步，皱了皱眉：“你还有什么遗言？”

顾衡看着他按在肋下的右手，平静地道：

“你怀里那半包花光了你娘子嫁妆、从东码头黑市买来的所谓‘百年龙涎草’……不用拿去喂你儿子了。”

轰！

原本昏暗死寂的牢房里，空气仿佛在一瞬间彻底抽空！

刀疤马整个人如同被九天玄雷当头劈中，原本佝偻的身躯猛地僵直，满脸横肉以肉眼可见的幅度疯狂抽搐起来！

“你……你说什么？！”

刀疤马猛地扑到木栅栏前，双手死死攥住粗糙的铁条，那一双布满血丝的浑浊双眼死死瞪着顾衡，声音尖锐得近乎变形：

“你个死到临头的犯官……你怎么知道？！”

他给快要咽气的独生子买药这件事，连县衙的同僚都不知道，甚至连他娘子的银簪也是昨天傍晚才典当给人牙子换了银钱，深夜独自摸去东码头交易的！

整个蓟县，绝不可能有第二个人知晓！

顾衡依旧坐在枯草堆上，神色淡漠得如同一尊俯瞰人间的泥塑神祗。

为了防止算力泄漏，他甚至没有启动第二次推理，仅仅凭借前世顶级战略专家的心理学冷读能力，继续给予对方毁灭性的心智重击：

“那是用烂树皮浸泡了曼陀罗根煮出来的假药。”

顾衡的声音不高，但每一个字，都像是一柄冰冷的解剖刀，精准地刺入刀疤马心脏最柔软的血肉里：

“药里掺了过量的生川乌。你儿子若是不喝，靠着参汤吊命，尚且能苟延残喘三天；若是你今晚回去把这碗毒汤灌进他肚子里……”

顾衡微微一顿，那双深邃幽黑的眼眸如深渊般凝视着刀疤马崩溃的瞳孔：

“不到子时，他便会七窍流血，全身抽搐而死。”

“扑通！”

没有任何犹豫，刀疤马双腿一软，整个人烂泥般重重跪倒在潮湿肮脏的泥地上！

冷汗瞬间湿透了他的整件差役短衫！

他颤抖着从怀里摸出那一包用油纸紧紧包裹着的暗黄色粉末，鼻尖凑上去猛地一嗅，果然闻到了一股极其细微、却令人作呕的麻舌腥味！

那是生川乌！剧毒的生川乌！

“仙长……活神仙！！”

刀疤马的心理防线在这一瞬间彻底决堤瓦解。

他在这间不见天日的死牢里当了二十年狱卒，见过无数喊冤叫屈的达官贵人，但从未见过任何一个人，能在身陷绝境、戴着死刑枷锁的关头，仅凭一眼，便看穿他全家生死的秘密！

这不是未卜先知，这是鬼神莫测的通天之术！

“求先生救救我儿！求先生救救马家唯一的独苗！”

刀疤马疯狂地在地板上磕头，额头撞在坚硬的青石板上，发出沉闷刺耳的咚咚声，鲜血混着泥浆四处飞溅：

“只要先生能救我儿子一命……我马三这条烂命就是先生的！劫狱！我放先生走！我今晚就护送先生出关！”

“劫狱？”

顾衡轻轻摇了摇头，眼底闪过一丝嘲弄与居高临下的从容：

“天地虽大，没有路引户籍，你能带我逃去哪里？不过是沦为草原蛮胡的刀下亡魂罢了。”

他缓缓伸出那双缠着铁链的双手，指关节在虚空中轻轻叩了叩木栅栏，声音沉静如水，却带着不容置疑的雷霆威严：

“把锁打开。”

“距离天亮还有三个时辰。”

“三个时辰内，我不但能让你儿子活命，还能让你看着……那位高高在上的陈县令，是怎么把这一身官皮扒下来，自己跪着爬进这间死牢里替我偿命的。”
