# 第12章 提调粮台：十七个Token的空头绞杀

秋风萧瑟，卷过幽州通判衙署高耸的青砖檐角。

满堂金芒未散，两口沉重的生铁大箱敞着，塞北双头狼马蹄金在初升晨曦下散发着森冷暗光。王修之与陈伯庸面如死灰，如烂泥般被套上死刑重枷，一路拖出辕门，沉重的生铁锁链在青石甬道上拖曳出刺耳的刮擦声。

“顾先生，”正三品巡按御史林文渊手按尚方宝剑，面色凝重，“王修之虽已伏诛，但幽州乃九边咽喉，驻军六万，兼管塞北榷场与辽东粮道。王修之盘踞近十载，盘根错节，全州钱粮账目如今成了一团乱麻。”

林文渊将一方雕刻玄武衔环的青铜官印与朱漆御赐令箭郑重推至顾衡面前：

“老夫需坐镇钦差行辕审讯要犯，八百里加急上奏京畿枢密院。这幽州总督粮台提调官的重担，唯有先生能担！三品以下文武，凭此令箭皆可先斩后奏。先生可有把握？”

顾衡神色淡然，伸手接下冰凉沉重的印信。

视网膜深处，微蓝光芒如水波般静静流淌：

【核心架构：Oracle-Core-X（400B MoE）】
【当前离线Token余量：9,999,999,573】
【KV Cache 驻留量：0（极简无状态运行）】

“林公放心。”顾衡衣袖微拂，平静道，“官僚系统的烂账，本质只是信息黑盒与寻租冗余。只要斩断混淆链路，算力之下，无所遁形。”

林文渊长舒一口气，肃然躬身一揖，随即带队直奔行辕。

然而，幽州官场的暗流比预想中来得更加迅猛。

林文渊前脚刚走不到半个时辰，衙署门外原本肃静的长街上，骤然炸响了震耳欲聋的喧嚣声！

“踏！踏！踏！”

沉重如雷的皮靴踏地声与铁甲撞击声由远及近，森寒杀气如潮水般涌来。

赵铁胆按住腰间雁翎刀，快步冲上台阶极目远眺，脸色骤变：“先生！不好了！幽州卫左营指挥同知钱彪，领着两千全副武装的营兵，把咱们粮台衙门围死了！”

长街尽头，两千名身披铁甲的营兵手持长矛大戟直指大门，齐声嘶吼：

“交出军饷！交出秋粮！！”
“王修之扣押我们三月饷银！今日拿不出粮食银子，老子们拆了粮台！！”

兵变！

王修之刚被收监，城防卫所竟在短短一个时辰内集结，以“追讨欠饷、军中绝粮”为名公然围逼官署！

与此同时，长街两侧商市一片大乱。

各处米粮铺面齐齐落下了包铁门板，门前贴着告示：“陈粮售罄，新谷未至；即日起，糙米每石三两二钱！”

原本六七百文一石的糙米，半日之内被生生哄抬近五倍！全城百姓惊惶哭嚎，暴动一触即发。

一阵马蹄声中，两道身影在亲兵簇拥下策马而至。

为首者身披正四品明光铠，满面横肉，正是幽州卫指挥同知钱彪；身后跟着一位身穿紫貂棉袍、戴满翡翠扳指的中年富商——幽州商会总把头、“万盛合”大东家沈万通。

钱彪翻身下马，大步踏上石阶，佩刀当啷作响。他轻蔑扫过赵铁胆等人，目光钉在顾衡身上：

“这位便是新任的顾提调？钱某是个粗人，只认实利！王修之犯法是他的事，可咱们幽州卫两万弟兄不能饿肚子！卫所三月没发粮饷，弟兄们听闻换了新官，特来讨个公道！”

沈万通亦上前，装模作样地拱手叹道：

“草民沈万通见过大人。钱将军所言极是！如今辽东粮荒，运河又阻，草民手里的万盛合虽有些存粮，但全是从江南高价垫资调来的。若提调大人能由官府出面，按每石三两银子将草民手里的四万石粮食包销下来，再以官盐引质押贴息……草民愿倾尽家财替朝廷解难！”

二人一唱一和，杀机毕露。

钱彪以两千哗变悍卒为刀，逼顾衡交权；沈万通以全城粮荒为盾，企图吞下通判府盐引，更逼官府以五倍天价接盘！

若顾衡不允，乱兵立刻冲入衙署将他乱刀剁碎；林文渊事后追查，也只能定性为“边卒哗变”，法不责众！

赵铁胆拔刀半寸，咬牙道：“先生！他们分明是串通好的，想逼咱们交出印信！”

面对森寒刀林与滔天咆哮，顾衡立于台阶之巅，瞳孔沉静如古井。

在系统架构师眼中，这是极为典型的人工流动性挤兑与卡特尔垄断敲诈。

他视线微移，精密扫视着前方的每一个微观特征：

其一，钱彪唇角残留着极细的深黄油脂，呼吸带着浓烈孜然烤肉味；带头叫喊的数十名营兵面色红润，眼底布满饱食后的血丝，打嗝伴着烈酒酸气，绝非绝粮三日之人。

其二，沈万通身后的车夫，皮靴边缘附着厚重的灰白泥浆与红色陶渣——那是城西三十里外、早已废弃的明代“黑龙潭古砖窑”独有的烧结矿！

其三，万盛合今晨进出城门的百余辆大车，车辙深陷三寸二分，出城时却轻快无痕！

数据在脑海瞬间对齐。

视网膜微光骤亮：

【系统指令：执行零样本超低功耗推理】
【输入上下文（13 Tokens）】：
“幽州粮荒逼宫。沈家车辙深沉，带碱泥炭灰，卫营兵饱食。求解囤粮暗仓与破局支点。”
【限制条件】：
“禁止冗余客套，输出长度严格限制在15字以内。”

嗡。微弱的神经脉冲一闪而逝。

【推理消耗：13 Input Tokens + 4 Output Tokens = 17 Tokens】
【Token 余额：9,999,999,556】

虚空之中，幽蓝字符凌厉浮现：

【粮藏城西砖窑暗渠，开仓断其现银。】

十七个Token！

钱彪见顾衡沉默，眼中凶芒大盛，猛拍刀柄厉吼：“顾提调！弟兄们耐心有限！拿不出四万石粮和三万两银，休怪营兵不认令箭！”

顾衡淡淡抬眼：“四万石粮？钱同知今晨在沈掌柜外宅吃的那顿烤全羊，味道可还肥美？”

话音一落，钱彪身躯猛地一僵，咆哮卡死在咽喉里！

顾衡负手前迈半步，目光如霜，直刺沈万通：“带头叫嚷的营兵，辰时刚在城西分食了沈掌柜送去的四口肥羊与八坛烧刀子，牙缝里的羊油腥味十步外都能闻到，也配在衙门前哭饿？！”

哗——！

阶下两千营兵阵脚大乱。后排不知情的兵卒惊愕万分，带头的几个什长更是羞愧捂嘴，连连后退！

“一派胡言！”沈万通心胆俱颤，尖叫道，“大人休要搬弄是非！城中无粮是铁证！”

“幽州当真无粮？”

顾衡冷然道：“沈大掌柜，你借王修之批文，将常平仓三万余石官粮以霉变耗损为由起运出库，连同低价陈粟，全数运往城西黑龙潭古窑暗渠！那处地下工事干燥通风，昨日子时至今日寅时，你用一百二十辆大车，将四万石粮食深埋地道！”

“你关闭所有粮铺哄抬至三两二钱，串通钱同知煽动哗变，妄图让官府按天价回购，吞尽三万官盐引！沈万通，本座可有一字冤枉你？！”

蹬蹬蹬！

沈万通如遭五雷轰顶，连退三步狠狠撞在旗杆上，面如死灰，满头冷汗如浆！

黑龙潭暗渠乃机密绝所，连伙计都被禁足，顾衡身居城内，怎会连车辙时辰与地道位置都了若指掌？！

“钱将军！杀了他！快动手杀了他！！”沈万通彻底崩溃狂呼。

“铿！”

赵铁胆长刀出鞘，雪亮刀锋瞬间贴在沈万通脖颈上，鲜血微渗，吓得沈万通瘫软在泥水中嚎哭！

顾衡俯瞰钱彪，语气冰寒刺骨：“钱彪，本座手持尚方令箭，专断三品以下生死。你若动兵，便是谋逆灭族；若就此收手，按受王修之胁迫论处。选吧。”

钱彪浑身颤抖，冷汗浸透内甲。看着顾衡那双幽深双眸与身侧瘫软的沈万通，他手中配刀当啷坠地，单膝跪地颤声道：

“末将……受奸商挑唆，险铸大错！全凭大人发落！末将愿戴罪立功！！”

两千营兵见状，齐刷刷抛下兵刃，跪伏长街！

顾衡当即令道：“钱彪，随赵铁胆领五百铁骑直扑城西黑龙潭古窑，起运四万石粮食回城！查封沈家所有商号，违令者斩！”

“遵命！！”钱彪如蒙大赦，翻身上马飞奔而去。

随后，顾衡对身侧文吏下达反垄断绞杀令：

“在两市张贴榜文：第一，粮台起获黑心奸商囤积私粮四万石，即刻设立平价仓，糙米按每石四百文敞开供应，凭户籍限购两斗！”

“第二，各处粮铺限申时前开门，粮价不得高于四百五十文；违者以北蛮同谋论处，抄没全产！”

以没收存量倾销市场，腰斩供给价格，瞬间击穿囤积同盟的心理底线！

不过三个时辰，四万石粮食如长龙押入城中，全城百姓涌上街头欢呼雷动。其余粮商吓破了胆，疯狂开仓以三百八十文竞相抛售，原本滔天的粮荒与兵变，在半日之内彻底烟消云散！

暮色低垂，顾衡立于衙署高阁，大氅在风中翻卷。

视网膜微光流转：

【任务结算：幽州粮台平准战】
【平息两千卫所兵变，瓦解粮枭卡特尔，查抄粮食四万石、白银七万两】
【全局消耗 Token：17】
【当前 Token 余额：9,999,999,556】

一百亿Token，九牛一毛未损。

然而，在赵铁胆刚送来的沈万通密室暗信中，赫然记录着一条血色谍报：北蛮老可汗得知阿卜杜被擒，已在王庭集结草原八万狼骑，誓要在初雪前踏平幽州！

大梁边关真正的灭顶暴风，已在地平线上隆隆作响。

顾衡微微阖眸，嘴角泛起冷冽弧度。

八万铁骑？

他的算力账本上，还有九十九亿九千九百多万枚筹码，正静候着这场天下大局的真正浪潮！
